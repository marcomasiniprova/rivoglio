# Collaudo UX — screenshot di Valerio

Qui Valerio mette gli screenshot di TUTTO Rivolio, ogni possibile percorso
utente, e Claude li analizza uno per uno con occhio critico da ingegnere di
web app consumer: cosa farebbe un utente vero, dove si perde, cosa confonde,
cosa migliorare per l'esperienza.

## Come metterli
- Cartella: `collaudo-ux/screenshot/`
- Nome del file, se puoi: `NN-cosa-e.png` (es. `01-verdetto-idoneo.png`,
  `12-pratica-chiusa.png`). Il numero tiene l'ordine del percorso. Se non hai
  tempo di rinominarli va bene lo stesso: li guardo comunque.
- Puoi mettere note in un file accanto se vuoi indicare cosa non ti torna.

## Cosa fa Claude
Guarda ogni foto, la confronta col codice, e per ognuna dice: cosa quadra,
cosa non quadra, imperfezioni, cose incoerenti o ripetute, flussi o ordini
da cambiare. Poi propone i fix e li fa.

## Nota tecnica
Gli screenshot in .png pesano e gonfiano il repo a ogni clone. Dopo la
revisione la cartella si svuota (i suggerimenti restano scritti, le foto no).
