# Skills di progetto

Qui vivono le skill che valgono SOLO per MicroStay Alert.
Una skill = una procedura ripetibile che altrimenti rispiegheresti ogni volta.

Formato: una cartella per skill, con dentro `SKILL.md`:

```
.claude/skills/
  nome-skill/
    SKILL.md
```

`SKILL.md` inizia con:

```
---
name: nome-skill
description: Usa quando <situazione precisa>. Fa <cosa>.
---
```

Candidate per questo progetto (da creare quando servono davvero, non prima):
- `aggiungi-fonte-offerte` — come si collega una nuova fonte prezzi
- `fine-sessione` — aggiorna STATO.md + verify + commit
- `nuovo-video` — genera lo script di un video corto da un deal reale
